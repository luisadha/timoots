Siapa yang saling follow dengan Anda?

Unggah data followers dan following dari ekspor data Meta. Semuanya diproses di browser Anda; tidak ada yang dikirim ke server dan tidak perlu login.

1. Masukkan data

Atau tempel daftar username
Cara mengambil data dari Meta
  1. Buka Pengaturan di Threads/Instagram, lalu Pusat Akun (Accounts Center).
  2. Pilih Informasi dan izin Anda, lalu Unduh informasi Anda.
  3. Pilih akun Threads, pilih data Followers and following, format JSON (atau HTML).
  4. Setelah siap, unduh dan ekstrak ZIP-nya. Jika followers dipecah menjadi beberapa file (mis. followers_1.json, followers_2.json), pilih semuanya sekaligus.

2. Hasil

    Tidak berafiliasi dengan Meta atau Threads. Data Anda tidak disimpan.
